# Movie Recommendation System

A graph-based movie recommendation system built using HTML, CSS, and JavaScript. The system intelligently connects over 20+ movies based on similarities in genre, director, and actors, resulting in higher recommendation accuracy and an engaging user experience.

## Features

- **Graph-Based Recommendations:** Utilizes graph database principles to connect movies and deliver accurate suggestions.
- **Real-Time Movie Recommendations:** Offers up to 5 instant suggestions based on user-selected genre preferences, reducing user search time by approximately 30 seconds.
- **Interactive User Interface:** An intuitive UI with auto-suggestions for 25+ movie titles and dynamic recommendations as users interact.
- **Scalable Structure:** Designed to handle datasets of over 100 movies while maintaining stable performance.
- **Improved User Engagement:** Recommendations are visually displayed, making it easier for users to explore and discover new movies.

## How It Works

- The recommendation engine builds a graph connecting movies by shared genres, directors, and actors.
- As users select their preferred genres, the system dynamically updates to show relevant movie suggestions.
- Auto-suggestion features streamline user input and discovery.
